# Quick start

Follow [START_HERE](../START_HERE.md), the single installation procedure. Recommended: Core + Default Workflow; files-only is valid and Router optional.

The [kernel-only example](../examples/kernel-only/README.md) demonstrates direct memory use; the [workflow example](../examples/default-workflow/README.md) shows Task/Report roles. Both are synthetic, not external human evidence.

The maintained `tools/first_use_probe.py` prepares a new synthetic workspace and optionally inspects native local Skill discovery; see [verification](VERIFY.md) and [platform limits](PLATFORM.md). Never overwrite an existing project or copy account credentials to complete a test.
