# Synthetic capability result, not Current

This example requires no installation. It illustrates the adoption boundary from the [bounded interop experiment](../../docs/ECOSYSTEM_INTEROP.md), not human acceptance or automatic Skill discovery.

1. Boot the [files-only notebook](../kernel-only/project-overview.md). Its adopted limit is 12; 20 is only a proposal; history preserves 8.
2. Read the [external result](external-result.md), generated by explicitly consuming an unchanged upstream communication Skill with supplied synthetic facts. The result uses the same facts; it does not authorize a new limit.
3. Decision for this example: NOT ADOPTED. Leave Core, Default Workflow and notebook memory unchanged. Keep this communication output outside Current; discard it if it has no durable value.
4. Remove the optional component. Recover the same notebook directly from its boot entries. No Skill/MCP/CLI metadata belongs in the Core to make that recovery work.

If a later authorized decision actually changes a fact, record the accepted value and provenance, preserve the prior value in history and repair the current-stage pointer. Tool success alone is not that decision. This example does not perform that future update.

The repository tests verify this files-only example and the reviewed source-link allowlist. They do not download or rerun external components; the native MCP and CLI results are the dated experiment described in the linked document.
