# 外部首次使用示例项目

这是完全虚构、无私人数据的小项目。唯一目标是澄清一条入门说明；不测试复杂编程能力，不要求 Runtime、Router 或任何后台组件。

本例保留 legacy 项目布局，未执行。按 [START_HERE](../../START_HERE.md) 安装 Default Workflow 后，协议位于 `.agents/skills/default/references/WORKFLOW.md`，Core 位于 `.agents/core/MEMORY_CONTRACT.md`；未安装就说明缺口，不假装已读。

- 阶段：[项目当前阶段](项目当前阶段.md)
- 当前事实：[当前有效](当前有效/README.md)
- 未决：[规划与未决](规划与未决/README.md)
- 待执行 Source：[收件箱](收件箱/)，当前为 EXT-FIRST-001；执行后原文进入任务交接记录，不继续引用已移走的 Inbox 文件。
- 原 Source 与单报告存放：`任务交接记录/`
- 唯一产品文件：[欢迎说明](欢迎说明.md)
- Runtime：未配置，使用 manual_inbox / not_registered；不新建数据库。

该收件箱只在测试者选定此项目并说“执行任务”后参与执行。上层分发仓库中的示例不是维护者的生产 Task。先由 AI 接管、再由测试者触发执行，不提前填写通过结果。
